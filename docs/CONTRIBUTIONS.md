# Project contributions vs. AESTRA (Liang et al. 2023)

This document highlights what this codebase adds or changes relative to the AESTRA paper (Draft v1, arXiv:2311.18326v1). Each item is grounded in code paths and config flags.

## Architecture deltas
- Proxy-conditioned encoder (new)
  - SPENDER can be conditioned by external activity proxies at the latent bottleneck via concatenation or FiLM.
  - Where: `src/modeling/models.py` → class `SPENDER(..., proxies_dim, proxies_proj_dim, conditioning='concat'|'film')`, `_prepare_proxies`, `film_gamma`, `film_beta`.
  - Config: `include_activity_proxies`, `activity_proxies_dim`, `proxies_proj_dim`, `conditioning_mode`.
- Optional rest-frame encoding (new)
  - Residuals can be shifted to the rest frame (using predicted RVs) before feeding the encoder, for both observed and augmented branches.
  - Where: `AESTRA.get_spender_pred(..., encode_in_rest_frame=True)`.
  - Config: `encode_in_rest_frame`.

## Losses and regularization
- Consistency loss is configurable (extension)
  - Support for both `mse` and sigmoid-style consistency; can be toggled.
  - Where: `AESTRA.get_losses()` → `loss_c_mse`, `loss_c` selected by `consistency_mode`.
  - Config: `consistency_mode` in {`mse`, `sigmoid`}.
- Smoothness penalty on activity spectrum (new)
  - L2 penalty on 1st/2nd derivatives of `y_act` to encourage smooth reconstructions.
  - Where: `loss_smooth(batch_yact, alpha, order)`.
  - Config: `smooth_alpha`, `smooth_order`.
- Latent–RV correlation penalties (new)
  - Penalize correlation between RVs and latents (or Δv and averaged latents over obs/aug pairs) during training to reduce activity leakage.
  - Where: `corr_loss_v_vs_S`, `corr_loss_pairs`; applied in `AESTRA.get_losses()` when `sigma_corr > 0`.
  - Config: `sigma_corr`.
- Activity supervision hook (new)
  - Optional supervised loss if a ground-truth activity component is available.
  - Where: `loss_activity(y_act, y_act_true, alpha_act)`; toggled in `AESTRA.get_losses()`.
  - Config: `loss_activity`, `alpha_act`.
- Rest-frame template supervision hook (new)
  - Penalize deviation of learned `b_rest` from a provided target.
  - Where: `loss_b_rest(b_rest_true, b_rest_pred, beta_brest)`.
  - Config: `beta_brest`; provide `b_rest_true` when constructing `AESTRA`.
- Weighted fidelity (practical extension)
  - `loss_fid` accepts per-pixel weights (e.g., from photon noise/SNR) to match data characteristics.
  - Where: `loss_fid(..., batch_weights, sigma_l)`.
  - Data: `weights_fid` generated by dataset builders.
- Cyclic ridge regularization (matches paper; generalized)
  - Implementation of `k_reg` cycling with `get_k_reg(k_reg_init, cycle_length)`; scaled by `sigma_y`.
  - Where: `loss_reg`.
  - Config: `k_reg_init`, `cycle_length`, `sigma_y`.

## Training and optimization
- Two-phase training with engineering support (extension)
  - Phase control (`rvonly`/`joint`), early stopping, mixed precision (`torch.amp`), optimizer/scheduler helpers, periodic plots and CSV logging, robust checkpointing (with storage-preserving fallback).
  - Where: `src/modeling/train.py` (experiment dirs, `save_experiment_checkpoint`/`load_experiment_checkpoint`, `EarlyStopping`, `train_phase`).
- Augmentation/interpolation controls (practical)
  - On-the-fly Doppler augmentation with linear or cubic interpolation and explicit extrapolation strategies.
  - Where: `src/interpolate.py` → `augment_spectra_uniform`, `shift_spectra_linear` (fast), `shift_spectra_cubic` (paper-style).

## Data and dataset pipeline
- SOAP-like dataset builder with options (new)
  - RASSINE normalization option, downscaling/smoothing, optional regrid, photon noise injection with per-pixel weights, GPU-optimized planet injection, and precomputed `spectra_no_activity`.
  - Where: `src/create_datasets.py` → `create_soap_gpu_paper_dataset`.
- RV Data Challenge builder (new)
  - Derives per-pixel sigma from SNR curve → weights; optional planet injection; stores sigma.
  - Where: `create_rvdatachallenge_dataset`.
- Activity proxies ingestion and robust normalization (new)
  - Loads CCF proxies (depth/FWHM/BIS), applies robust z-score with median/MAD; stores normalized proxies and med/mad.
  - Where: `load_activity_proxies_npz`, `robust_zscore_train_only`, `apply_robust_zscore`.
- Harmonized dataset + collate (practical)
  - `SpectrumDataset` reads standardized `.npz` including optional keys: `activity`, `spectra_no_activity`, `weights_fid`, `activity_proxies[_norm|_med|_mad]`.
  - `generate_collate_fn` returns batches with on-the-fly augmented spectra and proxies ready for model conditioning.
  - Where: `src/dataset.py`.

## Inference/diagnostics and plots
- Expanded visualization suite (practical)
  - Loss panels, full AESTRA analysis, latent space plots, correlation matrices, periodograms, and dataset-wide RV predictions; wired into training phases.
  - Where: `src/plots_aestra.py`.

- Loss toggles/weights: `consistency_mode`, `smooth_alpha`, `smooth_order`, `sigma_l`, `sigma_corr`, `loss_activity`, `alpha_act`, `beta_brest`, `k_reg_init`, `cycle_length`, `sigma_y`, `sigma_v`, `sigma_s`.
